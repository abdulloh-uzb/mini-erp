# Cost of goods sold uses moving weighted average

Each executed purchase updates a product's average cost per piece (store-wide, across all locations), and each sale line stores the average cost at the moment it is executed. NSBU 4 (p.62–63) allows average, FIFO and identified cost. We chose average over FIFO (MoySklad's method) because it needs no batch tracking and is easy to explain to a shop owner.
